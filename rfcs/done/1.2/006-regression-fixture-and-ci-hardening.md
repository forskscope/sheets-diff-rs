# RFC 006 — Regression Fixture and CI Hardening

**Status.** Implemented (1.2.0)
**Tracks.** Test coverage for stabilization fixes.
**Touches.** `tests/`, `tests/fixtures/`, `Cargo.toml` (`[dev-dependencies]`).

## Summary

Expanded the test suite to lock in all v1.2.0 fixes. Added unit tests for
A1 addressing, integration fixtures for wide columns, negative-path tests
for fallible constructors, and the CI stdout-hygiene check.

## Test layout delivered

```

    wide-columns-new.xlsx   (new — generated by rust_xlsxwriter)

  utils_address.rs          (RFC-003 unit tests)
  constructors.rs           (RFC-002/RFC-004 integration tests)
```
