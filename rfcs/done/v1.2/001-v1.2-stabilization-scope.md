# RFC 001 — v1.2 Stabilization Scope and Compatibility Policy

**Status.** Implemented (v1.2.0)
**Tracks.** Release boundary, compatibility, and sequencing for v1.2.0.
**Touches.** All of `src/`, `tests/`, `Cargo.toml`, `CHANGELOG.md`, and the
`rfcs/` directory itself.

## Summary

`sheets-diff` v1.2.0 is a focused stabilization release for the
field-reported `.xlsx` comparison defects found during GUI integration.
The release prioritizes correctness, no-panic integration, and regression
coverage while avoiding public model redesign that belongs in v2.

The release delivered two non-negotiable fixes:

1. A correct A1 address converter for the full Excel column range.
2. A fallible construction path that returns a structured error instead of
   panicking on workbook open/read failures.

It also delivered compatible constructor and diagnostic improvements.

## Background

Downstream GUI diff/merge applications use `sheets-diff` as a library,
not only as a CLI. In that environment:

- a dependency panic becomes a GUI crash or forces `catch_unwind` wrappers;
- wrong cell addresses directly mislead users;
- path-only input forces double I/O and lossy path conversion;
- stdout writes are not visible or controllable from a GUI application.

The v1.1.4 public model was simple and useful enough to preserve for this
stabilization release.

## Goals

- Preserve source compatibility for existing callers of `Diff::new(&str, &str)`.
- Add `Diff::try_new(...) -> Result<Diff, SheetsDiffError>` for no-panic callers.
- Fix A1 address generation across Excel's full supported range, including `XFD`.
- Add path-safe and reader-based constructors.
- Remove library stdout/stderr writes from the diff engine.
- Add regression tests for wide columns, corrupt/unreadable files, and stable ordering.

## Non-goals (deferred to v2)

- Replace `Option<String>` cell values with typed values.
- Redesign sheet changes into `SheetChange::{Added, Removed, Renamed}`.
- Add row/column alignment.
- Add cancellation, progress callbacks, or cell/time limits.
- Add `pub warnings: Vec<SheetWarning>` to `Diff`.

## Public API compatibility

The following v1.1.4 calls remain valid:

```rust
let mut diff = sheets_diff::core::diff::Diff::new("old.xlsx", "new.xlsx");
let cloned = diff.diff();
```

The following additions shipped in v1.2.0:

```rust
let diff = sheets_diff::core::diff::Diff::try_new("old.xlsx", "new.xlsx")?;
let diff = sheets_diff::core::diff::Diff::try_from_named_readers(
    "old.xlsx", old_reader,
    "new.xlsx", new_reader,
)?;
```
